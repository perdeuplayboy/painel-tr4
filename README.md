# Painel TR4

Painel central para a Mitsubishi Pajero TR4: um celular Android atrás de uma moldura
impressa em 3D, no lugar do display de relógio, data e temperatura. Mostra dados do
OBD2 (adaptador ELM327 BLE, como o Konnwei KW902) no formato do furo do painel.

Abra no Chrome do Android: https://perdeuplayboy.github.io/painel-tr4/

- Segure o relógio para abrir as configurações.
- Deslize para os lados para trocar de tela.
- Sem adaptador, use a fonte "Simulação".

Protocolo OBD, simulação e cálculo de consumo baseados no firmware ESP32 de
[rodrigo-brito/car-metrics](https://github.com/rodrigo-brito/car-metrics).
